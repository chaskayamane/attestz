# Test Attestz with Real Switch Chassis

The files located in this directory are intended to test Attestz with real switc
h chassis of your choice.

## Prerequisites

- A DUT (Device Under Test). This is the switch chassis of your choice. which mu
st be running an image that supports Attestz protocol.

- A PC with an ethernet port, running a Linux-based operating system. This will
be the host running the SUTs (Services Under Test).
