# Test Enrollz with Real Switch Chassis

The files located in this directory are intended to test Enrollz with real switch chassis of your choice.

## Prerequisites

- A DUT (Device Under Test). This is the switch chassis of your choice. which must be running an image that supports Enrollz protocol.

- A PC with an ethernet port, running a Linux-based operating system. This will be the host running the SUTs (Services Under Test).
